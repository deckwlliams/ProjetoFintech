# 💰 FinanTech Dashboard

Dashboard financeiro desenvolvido utilizando **HTML**, **CSS**, **Tailwind CSS** e **Chart.js**, com foco em controle financeiro pessoal, visualização de receitas e despesas e experiência responsiva para dispositivos móveis e desktop.

## 📋 Sobre o Projeto

O FinanTech Dashboard foi desenvolvido como atividade acadêmica da FIAP com o objetivo de aplicar conceitos de desenvolvimento web moderno utilizando Tailwind CSS.

A aplicação apresenta uma interface intuitiva para acompanhamento financeiro, permitindo visualizar:

* Saldo total
* Entradas e saídas
* Resultado mensal
* Gráficos financeiros
* Distribuição de gastos por categoria
* Histórico de transações
* Navegação responsiva para desktop e dispositivos móveis

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Tailwind CSS
* JavaScript
* Chart.js
* Lucide Icons

## 🎨 Funcionalidades

### Dashboard Financeira

* Resumo financeiro em tempo real
* Cards informativos
* Interface moderna e responsiva

### Gráficos

* Gráfico de linha para fluxo financeiro
* Gráfico de pizza para categorias de gastos

### Navegação

* Sidebar fixa para desktop
* Menu hambúrguer para dispositivos móveis
* Ícones interativos com Lucide Icons

### Histórico Financeiro

* Tabela de últimas transações
* Visualização de receitas e despesas
